# Frontend Documentation

> **Warning:** This content is AI inspired.

The frontend is a Next.js application (React) providing an interface for users to interact with the backend API.

## Features
- **Upload Zone**: A component for users to upload their medical records (`UploadZone.tsx`).
- **Results Dashboard**: Displays structured data returned by the backend (`ResultsDashboard.tsx`).
- **Marker Chart**: Visualizes the biomarker results (`MarkerChart.tsx`).

The application runs on Port 3000 and communicates with the FastAPI backend.
