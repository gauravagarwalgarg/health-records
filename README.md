# Health Records

> **Warning:** This content is AI inspired.

Health Records is a full-stack application that allows users to upload medical test PDFs, extracts their contents, and uses Google's Gemini AI to provide structured analysis, actionable insights, and health marker visualizations.

## Project Links

- **Documentation**: [https://gauravagarwalgarg.github.io/health-records/](https://gauravagarwalgarg.github.io/health-records/)
- **Repository**: [https://github.com/gauravagarwalgarg/health-records](https://github.com/gauravagarwalgarg/health-records)

## Features

- **Automated PDF Parsing**: Upload lab reports directly.
- **AI-Powered Analysis**: Leverages `gemini-3.7-flash` to structure unstructured medical data.
- **Interactive Dashboard**: Modern UI using Next.js to visualize biomarkers and provide patient suggestions.
- **Database Storage**: Simple SQLite storage for easy record-keeping.
